# autoFarm (오토팜 모니터)

태양광·배터리·워터펌프·보조 채굴장치로 구성된 소형 자동화 설비를 모니터링하는 대시보드.

## 구성
- `index.html` — 단일 페이지 대시보드. 아래 항목을 1분마다 갱신해서 표시
  - 배터리 전압/잔량(%), 상태 배지
  - 태양광 발전 효율, 역류 여부
  - 워터펌프 가동 상태 (예약 시간대 10:45~11:30)
  - 코인채굴 보조장치 가동 상태 (예약 시간대 12:45~16:00)
  - 날씨, 일출/일몰, 업타임
  - 최근 24시간 배터리 전압/태양광 효율 추이 차트 (Chart.js)
  - 과거 기록 히스토리 테이블(최대 48건)

## 동작 방식
라즈베리파이 등 로컬 서버(`kgu3405.duckdns.org`)의 `/api/autofarm/latest`, `/api/autofarm/history`를 호출해서 렌더링. 다크/나무(라이트) 테마 전환 지원.
